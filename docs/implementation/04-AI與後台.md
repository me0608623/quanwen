## 2. ZaiClient（`ai-audit/zai.client.ts`）

- **baseUrl**：`ZAI_BASE_URL ?? https://api.z.ai/api/paas/v4`
- **apiKey**：`ZAI_API_KEY`，未設仍可啟動，呼叫才拋 `http_401`
- **模型**：`ZAI_MODEL ?? glm-5.1`（auditModel，關鍵審核）、`ZAI_ROUTINE_MODEL ?? glm-4.6`（routineModel，草稿/建議/洞察）
- **推理鏈**：預設關閉（`ZAI_ENABLE_THINKING !== 'true'`），快 4-5 倍且品質相同
- **雙層 cache**：L1 in-memory LRU（200 entries / 5 分鐘）+ L2 Redis（key `zai:cache:`，fire-and-forget，故障降級 L1）；cache key = `sha256(model+temperature+messages+jsonMode)`
- **JSON mode**：`response_format: {type:'json_object'}`，`jsonChat` 自動抓 code fence
- **timeout/retry**：`ZAI_TIMEOUT_MS=60000`、`ZAI_MAX_RETRIES=2`、指數退避 500ms×2^(n-1)
- **錯誤**：ZaiError（timeout/http_5xx/http_4xx/http_401/network/parse），可重試者僅 5xx/network/timeout
- **Telemetry**：每次記 model/tokens/latency/attempts/finishReason/errorKind/promptKey/promptVersion/cacheHit，環形緩衝 500 筆，可接 Langfuse sink

## 3. AI 額度系統

來源：`common/guards/ai-quota.guard.ts`、`common/ai-usage.service.ts`

- **等級限額**：free 3 / vip 50 / vvip ∞（註：PLAN_CONFIG 標 free=5，兩處不一致，以實際 service 為準）

## 6. 通知系統（`notifications/`）

**類型**（`notification_type` enum）：`survey_approved`、`survey_rejected`、`new_response`、`response_milestone`、`daily_response_digest`、`reward_issued`、`system`

**Endpoint**：`GET /notifications`（最新 50）、`/unread-count`、`PUT /read-all`、`/:id/read`

**Email 推播**（`EMAIL_TYPES = {survey_approved, survey_rejected, new_response, system}`）：
- `new_response` 節流：同用戶 15 分鐘只寄一封（QUA-203），其餘仍建 in-app
- 每日摘要（QUA-200）：`surveyorProfiles.responseNotifMode='daily_digest'` 時跳過即時信，改 cron 每日 08:00（UTC 00:00）聚合 `sendDailyDigests`
- 全域條件：`email_verified` 且 `emailOptOut=false` 且 email 非 `.placeholder` 結尾

**建立**：`NotificationsService.create()` 寫表 + 判斷 EMAIL_TYPES fire-and-forget 寄信。

## 7. 寄信（`mail/mail.service.ts`）

- **SMTP**：`SMTP_HOST ?? smtp.gmail.com`、port 587、`MAIL_FROM ?? QuanWen <noreply@quanwen.tw>`
- **用途**：驗證信（24h）、通知信、受試者感謝信、每日摘要信、密碼重設信（1h）
- **降級**：dev 無 SMTP 設定 → `[noop]` log 靜默跳過
- **安全**（Phase F.1）：所有用戶輸入 `escapeHtml()`，內聯樣式防 XSS；驗證/重設信失敗 re-throw（業務關鍵），通知/摘要信失敗只 log

## 8. 申訴（`responses/appeals.service.ts`）

- **狀態**（`appeal_status`）：`pending → approved/dismissed`
- **受試者**：`POST /tasks/responses/:id/appeal`（reason 5-2000，限 rejected 填答，每 response 一次）、`GET /tasks/appeals`
- **通過**：response → `rewarded`、補配額（達標自動關閉）、補發獎勵（fixed）、reputation +5、發通知
- **駁回**：記 adminNote（5-500）+ 發通知
