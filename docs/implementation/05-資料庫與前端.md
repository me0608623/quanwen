# 05 · 資料庫與前端

> 範圍：`apps/api/src/db/schema`、`apps/web/src`、`packages/*`
> 來源：原始碼盤點（2026-06-15）

## 1. 資料表清單

### 使用者與認證
- **users**：主表。`email`(unique)、`passwordHash`、`role`、`tier`、`status`、`emailVerified`、`*Token`、`deletedAt`（軟刪）
- **oauthAccounts**：OAuth 綁定。`provider`、`providerAccountId`、token
- **respondentProfiles**：受試者檔案。年齡/性別/地區/職業/產業/教育、`reputationScore`、`completionRate`、`isOnboardingDone`、`suspendedUntil`
- **surveyorProfiles**：問券方檔案。`institutionName`、`isVerified`、`responseNotifMode`
- **reputationHistory**：信譽變動（delta/newScore/reason）
- **interestTags** / **respondentTags**：標籤目錄 + 多對多

### 問卷
- **surveys**：問卷主表。狀態/類型/分類、AI 審核欄、獎勵（rewardType/rewardPoints/rewardMode/deadlineTier）、抽獎欄、配額（targetCount/completedCount）、樣式（theme JSONB/coverImageUrl/welcomeImages）、感謝頁、外部連結、品牌優惠券、排程（scheduledPublishAt/autoCloseAt/autoCloseAfterN）、`audienceCriteria` JSONB
- **surveyQuestions**：題目。type/title/sortOrder/isRequired/imageUrl/`config` JSONB
- **questionOptions**：選項
- **surveyLogicRules**：跳題邏輯（condition/action/target）
- **userCoupons**：企業優惠券夾（uniqueIndex responseId 冪等）
- **surveyAiReports**：AI 報告持久化（uniqueIndex surveyId+reportType）

### 填答
- **surveyResponses**：填答。status、`qualityScore`、`qualityBreakdown` JSONB、sentiment、antiCheatScore、`behaviorLog` JSONB、fillDurationSeconds、fingerprintId。unique(surveyId, respondentId)
- **responseAnswers**：每題答案（textAnswer/selectedOptionIds JSONB/ratingValue）

### 金流
- **wallets**：`cashBalance`、`lockedCash`、`pointsBalance`、`version`（樂觀鎖）
- **transactions**：unique(externalProvider, externalRef) + uniqueIndex(relatedResponseId, type)
- **journalEntries**：複式分錄（accountName/debitAmount/creditAmount）
- **kycVerifications**：PII cipher 欄位 + 證件 URL + 審核
- **pointShopItems** / **pointRedemptions**：商城商品 + 兌換（pinCodeCipher 加密）
- **spinChances** / **spinRecords**：轉盤次數 + 紀錄
- **surveyLotteryResults**：抽獎結果 + 履約/平台驗證/介入/領取確認多階段追蹤

### 其他
- **mutualPairs**：互惠配對（A/B 雙方欄位 + status + expiresAt；uniqueIndex aSurveyId 限進行中唯一）
- **notifications**：通知
- **responseAppeals** / **importAppeals**：填答申訴 / 匯入申訴
- **dailyUsage**：AI 每日額度
- **zaiCallLog**：LLM telemetry

## 2. 資料庫雙模式

來源：`db/database.module.ts`

- **PGlite in-memory**（`USE_PG_MEM=true`）：`@electric-sql/pglite`，啟動時 `client.exec()` 建全部 enum/table/index + seed（3 測試帳號 `user{,1,2}@quanwen.com` 密碼 `000`、demo respondents、樣本問卷）。每次全量重建、無持久化。
- **真實 PostgreSQL**（預設）：node-postgres + Drizzle，需 `pnpm db:push`
- **DbExecutor 型別**：service 方法可「自開 transaction」或「掛在呼叫方 transaction」，達成跨 service 單一原子交易

> ⚠️ CLAUDE.md 規則：新增表/欄位必須三處同步 `schema/*.ts`、`database.module.ts` PGlite DDL、`test-helpers/pglite-ddl.ts`，否則 schema drift。pgEnum 新增值 `drizzle-kit push` 不套用，須手動 `ALTER TYPE ADD VALUE` 補 Neon。

## 4. 前端資料層

- **api.ts**：axios，`baseURL = NEXT_PUBLIC_API_URL ?? http://localhost:3001/api/v1`，request interceptor 自動附 `Bearer`（從 localStorage via `token.ts`），response interceptor 統一處理 401
- **TanStack Query hooks**（`src/hooks/use-*.ts`）：
  - `use-auth`、`use-profile`、`use-surveys`、`use-responses`、`use-wallet`、`use-shop`、`use-spin`、`use-mutual`、`use-admin`、`use-admin-users`、`use-admin-audit`、`use-analytics`、`use-notifications`、`use-import-appeals`、`use-pricing`
  - 每個 hook 管一個 domain，mutation 成功後 invalidate 相關 query
- **Zustand**：`behavior-tracker`（輕量 client state）

## 5. SurveyJS 渲染與 survey-editor

- **surveyjs-adapter.ts**：`quanswenToSurveyJs()` 把券問 PublicSurvey v1 轉 SurveyJS model。題型對應：single_choice→radiogroup/dropdown、multiple_choice→checkbox、text→text/numeric、rating→rating、matrix→matrix。支援 visibleIf 跳題、題目圖片、其他選項、反向題、隨機化
- **survey-editor 元件群**（`components/survey-editor/`）：
  - `survey-editor-shell`（左側 Questions/Styling/Rewards/Settings + 中央編輯 + 右側預覽）
  - `question-block-list` + `question-editor`（拖拽排序，Content/Logic 兩 tab）
  - `ai-draft-panel` + `ai-improve-panel`（AI 協作）
  - `rewards-panel`（獎勵/加急/品牌券）
  - `survey-style-panel` + `welcome-images-editor`（主題色/字體/封面/感謝頁）
  - `audience-targeting`（受眾篩選）
  - `survey-preview-*` + `SurveyRendererSurveyJS`（即時預覽）
  - `anti-cheat-panel`、`image-uploader`、`rating-scale`、`pricing-advice-card`
- **行為追蹤**（`lib/behavior-tracker.ts`）：填答時無感蒐集視窗切換/按鍵/滑鼠/貼上/每題停留，submit 時送後端供 Layer 1 評分；`detectIntervention` 前端即時提示異常
