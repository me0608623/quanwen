# QuanWen 行銷頁內容 Brief（首頁 + 5 子頁）

> 搭配 `DESIGN.md` 一起讀。DESIGN.md 管「長什麼樣」，本檔管「說什麼、排什麼區塊」。
> 語言：繁體中文（台灣用語）。所有頁面共用 `MarketingNav` + `MarketingFooter`。

## 鐵律（務必遵守）

1. **不可出現 AI 模型 / 廠商名**（GLM、GLM-5.1、Z.ai、OpenAI…）。一律寫「AI 品質審核」「AI 數據分析」「AI 灰區裁決」「AI 深度語義分析」。
2. **互惠問卷是主視覺**。首頁 hero 由互惠領銜，其餘賣點依序：三層 AI 審核 → 雙邊媒合+在地通路 → 一帳號全功能 → 信任三件套。
3. **金流用語合規**：受試者那側講「我的收益 / 待領獎勵」，**絕不**講「儲值」。平台「零持股、綠界 ECPay 託管」。
4. 文案要具體、可信，不浮誇；數字若非真實請標示為示意（例：見證可寫「— 某頂大社會科學研究所」這種匿名）。
5. CTA 一律導向 `/auth/register`（主）與 `/auth/login`（次）。

## 共用導覽 / 頁尾

**MarketingNav**（奶油底，sticky）：
- 左：`QW` 方塊字標 + 「券問 QuanWen」
- 中：產品優勢 `/features`、解決方案 `/solutions`、整合 `/integrations`、價格 `/pricing`、客戶故事 `/stories`
- 右：登入（text-link `/auth/login`）、免費開始（珊瑚主按鈕 `/auth/register`）
- mobile：漢堡 → 全幅奶油 sheet

**MarketingFooter**（深墨底，4 欄）：
- 產品：產品優勢 / 解決方案 / 整合 / 價格
- 公司：關於我們 / 客戶故事 / 聯絡我們
- 資源：常見問題 / 部落格 / 開發者
- 法務：服務條款 `/terms` / 隱私權政策 `/privacy`
- 底列：© 2026 券問 QuanWen · 為真實數據而生 · 綠界 ECPay 金流託管
